# Дашборд образовательных метрик для Grist

Read-only Custom Widget для таблицы с данными по потокам. Виджет показывает:

- фильтры по курсу, типу потока, году и кварталу;
- тип потока `b2c` выбран по умолчанию;
- переключение детализации «квартал / месяц»;
- KPI: число студентов, окончившие, % CoR и % успеваемости;
- динамику % CoR и % успеваемости;
- количество всех студентов по периодам;
- детальную таблицу потоков с сортировкой от более поздней даты окончания к более ранней.

Потоки без даты окончания и потоки, дата окончания которых ещё не наступила, не участвуют в KPI, графиках и детализации.

## Источник показателей

Виджет использует готовые значения из таблицы Grist:

- `Всего студентов` — `$total_new`;
- `CoR` — `$total_cor`;
- `Окончили обучение` — `$total_completed`;
- `Набрали >50%` — `$total_scored_more_half`;
- `%CoR` — `$CoR`;
- `% Успеваемость` — `$completed`.

Проценты для каждой строки не рассчитываются внутри виджета. В детализации выводятся значения непосредственно из таблицы. Для KPI и точек графика при выборе нескольких потоков количественные значения суммируются, а уже готовые проценты объединяются с весом соответствующих количественных колонок: `%CoR` — по `$total_cor`, `% Успеваемость` — по `$total_completed`.

Колонка процента может хранить значение как `0,75` или `75`; оба формата будут отображены как `75%`.

Цвета % CoR и % успеваемости в таблице:

- от 75% — зелёный;
- от 50% до 74,9% — жёлтый;
- менее 50% — красный.

## Публикация через GitHub Pages

1. Создайте репозиторий GitHub.
2. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `app.js`.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`.
5. После публикации скопируйте адрес страницы вида `https://USERNAME.github.io/REPOSITORY/`.

Для предварительного просмотра вне Grist добавьте к адресу `?demo=1`.

## Подключение в Grist

1. На странице документа выберите **Add New → Add Widget to Page**.
2. Выберите **Custom**, затем таблицу с данными.
3. В настройках виджета укажите опубликованный URL.
4. Разрешите уровень доступа **Read selected table**.
5. Заново сопоставьте поля после обновления виджета:

| Поле виджета | Колонка Grist |
|---|---|
| Курс | Курс |
| Поток | Поток |
| Тип потока | `$type_potok` |
| Дата окончания | Точная дата окончания, если она есть — необязательно |
| Месяц окончания | Месяц окончания |
| Квартал окончания | Квартал окончания |
| Год окончания | Год окончания |
| Всего студентов | `$total_new` |
| CoR | `$total_cor` |
| Окончили обучение | `$total_completed` |
| Набрали >50% | `$total_scored_more_half` |
| % CoR | `$CoR` |
| % Успеваемость | `$completed` |

Системные имена новых полей в конфигурации виджета совпадают с ID колонок Grist, поэтому Grist может сопоставить их автоматически. Проверьте сопоставление в панели настройки после замены файлов.

## Пустая выборка

Если выбранная комбинация фильтров не содержит данных, виджет сохраняет панель фильтров и показывает кнопку **«Сбросить фильтры»**. Перезагрузка страницы не требуется.

## Как определяется завершение потока

- Если сопоставлена точная колонка **Дата окончания**, используется она.
- Если точной даты нет, виджет использует **месяц и год окончания** и считает поток завершённым после окончания соответствующего месяца.
- Если нельзя определить дату окончания, строка не отображается.
